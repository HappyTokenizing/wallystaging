# Repository guidance

For logo additions and refreshes, follow **Logo sourcing policy** in `README.md`.
The user's standing preference is to prioritize artwork from the project's official X or other social profile over website favicons. Preserve replaced artwork in logo history.

For website page changes, read **Public pages and publishing** in `README.md`. Edit `templates/site.html` and the shared source files, run `npm run build`, and commit generated pages with their sources.
